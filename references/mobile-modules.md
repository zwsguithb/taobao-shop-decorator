# 淘宝手机端装修模块库

> 用途：定义手机端装修可用的模块类型、配置项、尺寸与适用场景，供方案设计与自动执行阶段使用。
> 模块名称为后台常见文案，实际以页面为准。

## 1. 模块类型总览

| 模块 | 后台常见名称 | 首页 | 详情页 | 说明 |
|---|---|---|---|---|
| 店铺头图 | 店铺招牌 / Banner | ✅ | ❌ | 顶部品牌视觉，常含 Logo+标语 |
| 轮播图 | 轮播 / 焦点图 | ✅ | ❌ | 多张图自动切换，放主推活动 |
| 图文导航 | 图文导航 / 金刚区 | ✅ | ❌ | 分类入口图标矩阵（4-10 个） |
| 商品分组 | 商品分组 | ✅ | ✅ | 按分组展示商品卡片列表 |
| 商品列表 | 商品 / 宝贝推荐 | ✅ | ✅ | 自定义商品展示 |
| 优惠券 | 优惠券 | ✅ | ❌ | 领取优惠券入口 |
| 营销活动 | 活动 / 营销 | ✅ | ✅ | 活动海报、满减、限时 |
| 公告 | 公告 / 店铺公告 | ✅ | ❌ | 滚动公告条 |
| 自定义区块 | 自定义 / 文本 | ✅ | ✅ | 富文本、长图、自定义 HTML 区块 |
| 客服 | 客服 / 在线客服 | ✅ | ❌ | 客服入口 |
| 关联推荐 | 关联推荐 / 搭配 | ❌ | ✅ | 详情页推荐关联商品 |
| 图文详情 | 图文详情 | ❌ | ✅ | 商品详情长图文 |

## 2. 模块配置项与尺寸

### 2.1 店铺头图 / Banner（首页顶部）
- **尺寸**：750 × 420（推荐比例 16:9 变体，具体以后台模板为准）
- **配置项**：图片、跳转链接（可选）
- **规格字段**：`{type: "banner", title: "主视觉", image: "banner_main.png", link: ""}`

### 2.2 轮播图
- **尺寸**：750 × 420 / 张，建议 3-5 张
- **配置项**：多张图片，每张可配独立跳转链接
- **规格字段**：`{type: "carousel", images: ["carousel_01.png", ...], links: [...]}`
- **执行要点**：后台需逐张上传，上传后按规格顺序核对

### 2.3 图文导航（金刚区）
- **尺寸**：图标 150 × 150（含文字合成图），一行 4-5 个，共 1-2 行
- **配置项**：图标+文字+跳转链接
- **规格字段**：`{type: "nav", items: [{label: "新品", icon: "nav_01.png", link: ""}, ...]}`
- **执行要点**：常见入口为 新品/热卖/优惠券/客服/全部宝贝，链接可选择商品分组或搜索页

### 2.4 商品分组
- **尺寸**：商品卡片图 750 × 750（主图）
- **配置项**：分组标题、选择商品或按分组规则自动拉取
- **规格字段**：`{type: "product_group", title: "新品首发", group_query: "新品", products: [...]}`
- **执行要点**：后台通常支持「按分组/按条件选品」，优先使用条件选品（维护成本低）；必须指定具体商品时逐条添加

### 2.5 优惠券模块
- **配置项**：选择已创建的优惠券（需先在营销中心创建）
- **规格字段**：`{type: "coupon", coupon_id: "", title: "新人券"}`
- **执行要点**：若无现成优惠券，先提示用户创建，或跳过该模块并在方案中标注

### 2.6 营销活动模块
- **尺寸**：750 × 400 活动图
- **配置项**：活动图、跳转链接
- **规格字段**：`{type: "promo", title: "618 大促", image: "promo_01.png", link: ""}`

### 2.7 自定义区块 / 详情长图
- **尺寸**：750 × N（N 按内容高度，建议每屏 ≤ 1500px 便于加载）
- **配置项**：富文本 / 图片 / HTML 源码
- **规格字段**：`{type: "custom", title: "品牌故事", image: "detail_long_01.png"}`
- **执行要点**：详情页长图建议按 750 宽设计稿切分多段上传，避免单图过大

### 2.8 客服模块
- **配置项**：客服账号选择（默认店铺主账号）
- **规格字段**：`{type: "service", label: "在线客服"}`

## 3. 首页推荐模块顺序（默认模板）

```
1. 店铺头图 Banner（品牌主视觉）
2. 图文导航 金刚区（4-5 个分类入口）
3. 轮播图（主推活动 3-5 张）
4. 优惠券模块（如有）
5. 商品分组 1（新品）
6. 营销活动模块（大促海报）
7. 商品分组 2（热卖）
8. 商品分组 3（清仓/其他）
9. 客服模块
```

> 模板文件：`assets/templates/homepage_default.json`，可作为 build_decoration_spec.py 的默认合并底稿。

## 4. 详情页推荐模块顺序（默认模板）

```
1. 图文详情（商品卖点长图，放商品详情前部）
2. 关联推荐（搭配/相似商品 4-8 个）
3. 营销海报（满减/赠品活动图）
4. 品牌故事/售后说明（自定义区块）
```

> 模板文件：`assets/templates/detail_default.json`。

## 5. 选型规则（方案设计时）

- 用户强调「转化」→ 优先：商品分组、优惠券、营销活动、关联推荐。
- 用户强调「品牌」→ 优先：头图 Banner、自定义区块品牌故事、统一色系。
- 用户强调「上新」→ 优先：轮播、商品分组（新品）、公告。
- 用户强调「清仓」→ 优先：商品分组（清仓）、营销活动（限时折扣）。
- 模板块数控制：首页建议 6-10 个模块，过多影响加载与体验；详情页 3-5 个区块。
