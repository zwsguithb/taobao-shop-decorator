# 淘宝卖家中心后台操作指南

> 用途：指导浏览器自动化访问淘宝店铺装修后台，并正确导航到「手机端装修」页面。
> 注意：淘宝后台页面结构会不定期改版，本指南中的路径/文案为常见形态，执行时以页面实际文案为准，用「可见文本定位优先」策略（见 execution-playbook.md）。

## 1. 入口地址

| 入口 | 地址/路径 | 说明 |
|---|---|---|
| 卖家中心（新） | `https://myseller.taobao.com` | 当前主流入口，登录后直达卖家工作台 |
| 卖家中心（旧） | `https://myseller.taobao.com/app/seller-portal-web/home` | 部分账号跳转形态 |
| 千牛工作台 | `https://work.taobao.com` | 商家工作台，可从这里进入店铺装修 |
| 装修后台直达（尝试） | `https://myseller.taobao.com/app/shop-decoration-web/home` | 若直达失败，按下面导航路径走 |

## 2. 登录状态要求

- 必须使用**用户已在本地 Chrome 登录淘宝卖家账号**的会话（CDP 复用，见 execution-playbook.md）。
- 若访问上述地址被重定向到登录页（`login.taobao.com`）→ 立即暂停自动化，提示用户手动登录后再继续。
- 登录页特征：URL 含 `login.taobao.com`、出现「扫码登录 / 密码登录」切换、或滑块验证组件。

## 3. 导航路径（卖家中心 → 手机端装修）

从卖家中心首页出发，常见导航路径（任选其一，按页面实际可用项执行）：

```
路径 A（推荐）：
卖家中心首页 → 左侧菜单「店铺」→「店铺装修」→ 装修页面右上角「手机店铺装修」标签/链接

路径 B：
卖家中心首页 → 顶部「店铺管理」→「店铺装修」→ 切换到「手机版」装修

路径 C（千牛入口）：
千牛工作台 → 「店铺装修」→ 手机端装修
```

关键标识文案（用于文本定位）：`店铺装修`、`装修`、`手机店铺`、`无线店铺`、`手机版`、`移动端`。

## 4. 手机端装修后台页面结构

进入手机端装修页后，典型页面结构：

```
┌─────────────────────────────────────────────┐
│ 顶部工具栏：保存草稿 / 预览 / 发布           │
├──────────────────────┬──────────────────────┤
│ 左侧：模块库           │ 中间：手机预览画布     │
│  ├─ 基础模块           │ （750px 手机框，      │
│  │   （图片/文本/导航/…）│   显示当前已搭模块）  │
│  ├─ 营销模块           │                      │
│  │   （优惠券/活动/…） │                      │
│  └─ 商品模块           │ 右侧：模块配置面板     │
│      （商品分组/列表/…）│ （选中模块后出现：    │
│                        │   图片上传/文案/链接） │
└──────────────────────┴──────────────────────┘
```

- **模块库（左侧）**：可拖拽或点击「+」将模块加入画布。
- **预览画布（中间）**：模拟手机屏幕，展示装修效果，可点击选中模块。
- **配置面板（右侧）**：选中模块后出现，配置图片、文案、跳转链接、排序。
- **顶部工具栏**：`保存草稿`、`预览`（生成预览链接）、`发布`。

## 5. 关键操作清单

| 操作 | 做法 |
|---|---|
| 新增模块 | 左侧模块库点击模块卡片（或拖拽到画布） |
| 选中/编辑模块 | 点击画布中的模块，右侧出现配置面板 |
| 上传图片 | 配置面板「图片」区域 → 上传 → 选择本地素材文件（先上传到淘宝图片空间，或直接选择本地文件） |
| 配置文案 | 配置面板文本输入框，输入规格中的文案 |
| 配置跳转链接 | 链接选择器：商品链接 / 活动链接 / 自定义 URL |
| 调整顺序 | 画布中拖拽模块，或模块操作按钮「上移/下移」 |
| 删除模块 | 模块操作按钮「删除」（仅在用户明确要求时执行） |
| 保存草稿 | 顶部「保存草稿」 |
| 预览 | 顶部「预览」，生成 H5 预览链接，可用手机扫码或浏览器打开 |
| 发布 | 顶部「发布」→ 确认弹窗 → 发布成功（必须经用户确认） |

## 6. 图片空间（素材上传前置）

- 淘宝装修后台通常要求图片先存在于**淘宝图片空间**：路径为 卖家中心 → 店铺 → 图片空间（或装修配置面板内直接提供「上传新图片」）。
- 上传后获得图片 URL，配置模块时直接引用。
- 批量上传时注意：图片空间单张限制通常 ≤ 3MB、格式 JPG/PNG/GIF，超限会失败。

## 7. 常见页面文案速查（用于文本定位）

- 入口：`店铺装修` / `装修市场` / `手机店铺`
- 工具栏：`保存草稿` / `预览` / `发布` / `立即发布`
- 模块名：`图片` / `图文导航` / `轮播` / `商品分组` / `商品` / `优惠券` / `营销活动` / `自定义区块` / `客服`
- 弹窗：`确定` / `确认发布` / `发布成功` / `保存成功`
