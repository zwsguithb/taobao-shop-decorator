# 浏览器自动化执行手册（Playbook）

> 用途：指导自动执行阶段使用浏览器自动化复用已登录会话，完成淘宝手机端装修。
> 核心原则：**登录态复用、文本定位优先、边做边截图、止步于草稿、发布需确认**。

## 1. 执行层选择

| 执行层 | 适用场景 | 使用方式 |
|---|---|---|
| `web-access`（推荐） | CDP 直连本地 Chrome，天然复用登录态 | 按其 SKILL.md 连接本地 Chrome 调试端口，直接操作页面 |
| `playwright-browser-automation` | 需独立浏览器实例 | 用其 API 启动浏览器；**注意登录态问题**——优先 connectOverCDP 到用户已登录的 Chrome，否则引导用户在其控制的浏览器中完成登录 |
| 其他浏览器自动化能力 | 视可用性 | 前提：能复用已登录会话或允许用户手动完成登录 |

**选择规则**：
1. 检查已安装技能列表中是否有 `web-access` → 有则优先使用。
2. 无 → 检查 `playwright-browser-automation` 等。
3. 都没有 → 停止自动执行，交付方案+素材包+手动操作指引，并提示用户安装浏览器自动化 Skill 后重试。

## 2. 连接与登录态检查

1. 按执行层要求连接浏览器（CDP 或 Playwright connectOverCDP）。
2. 导航到 `https://myseller.taobao.com`，检查是否处于已登录状态：
   - 已登录：页面显示卖家工作台/店铺信息，URL 不含 login。
   - 未登录：URL 含 `login.taobao.com` 或出现扫码框 → **暂停自动化**，明确告知用户「请在弹出的浏览器中手动完成登录」，等待用户确认后再继续。
3. 登录态检查必须每次执行都做（会话可能过期）。

## 3. 定位策略（重要）

淘宝后台 DOM 会改版，**禁止只依赖写死的 CSS 选择器**。按以下优先级定位元素：

1. **可见文本**：`get_by_text("店铺装修")`、`get_by_role("button", name="保存草稿")`。
2. **placeholder / label**：输入框用 placeholder 或相邻 label 文本。
3. **语义角色**：button / link / tab / heading。
4. **相对定位**：先定位稳定容器（如「手机预览」区域），再在其内部查找目标。
5. **固定选择器兜底**：仅当上述均失败时使用；失败时改用文本匹配，并在执行记录中标注「页面结构可能已改版」。

等待策略：页面跳转/异步加载统一用显式等待（等待目标文本可见，超时 10-15s），避免固定 sleep。

## 4. 执行流程（逐模块操作）

### 4.0 前置
1. 打开装修后台（见 taobao-backend-guide.md 的导航路径），切换到**手机端装修**页签。
2. 对当前装修状态**整页截图**存入 `backup/`（回滚依据）。
3. 记录当前已存在的模块列表（截图 + 文本提取），**默认不删除**任何现有模块，新模块追加。

### 4.1 新增模块
```
1. 定位左侧模块库（文本特征：模块名列表）
2. 按规格顺序逐个模块：
   a. 点击/拖拽模块卡片加入画布
   b. 等待画布中出现对应模块（文本/结构确认）
   c. 截图确认
```

### 4.2 配置模块内容
```
1. 点击画布中的目标模块 → 右侧配置面板出现
2. 按规格配置：
   - 图片：点上传 → 选择本地文件（assets_output/ 下对应文件）→ 等待上传完成
   - 文案：填入规格文案（注意输入框清空后填入，避免残留）
   - 链接：选择链接类型 → 搜索/粘贴链接
3. 配置完成后点击面板「确定/完成」保存该模块配置
4. 截图确认
```

### 4.3 排序调整
```
按规格顺序核对画布模块排列：
- 需要前移/后移的模块，用模块操作按钮（上移/下移）或拖拽
- 每调整一次截图确认
```

### 4.4 保存草稿
```
1. 全部模块完成 → 点击顶部「保存草稿」
2. 等待「保存成功」提示
3. 整页截图存档
4. 向用户展示截图，等待确认
```

### 4.5 发布（用户确认后）
```
1. 点击顶部「发布」（或「立即发布」）
2. 处理确认弹窗：核对弹窗文案后点「确定/确认发布」
3. 等待「发布成功」提示，截图存档
4. 用预览链接打开手机端效果，最终截图验证
```

## 5. 验证清单（发布前逐项核对）

- [ ] 首页所有规格模块均已出现在画布（对照 decoration_spec.json 的 modules 数组）
- [ ] 素材全部上传成功且无占位图/裂图（截图肉眼检查）
- [ ] 文案与规格一致，无错别字、无残留默认文案
- [ ] 跳转链接已配置（商品/活动/分组链接有效）
- [ ] 模块顺序与规格一致
- [ ] 无意外删除的原有模块（对照备份截图）
- [ ] 草稿已保存；用户确认后才发布

## 6. 故障处理

| 故障 | 处理 |
|---|---|
| 登录过期/被登出 | 停止自动化，请用户重新登录，再继续 |
| 验证码/滑块出现 | 停止自动化，请用户手动通过，再继续 |
| 元素找不到 | 换定位策略（文本→角色→相对定位），仍失败则截图让用户确认页面是否改版 |
| 上传失败（超 3MB/格式错） | 压缩或转格式后重传（PNG→JPG），见 design-system.md 导出要求 |
| 图片空间容量满 | 提示用户清理或使用已有图片 URL |
| 模块配置保存失败 | 截图记录错误，回退重试一次，仍失败则记录并询问用户 |
| 后台改版找不到入口 | 截图当前页面，询问用户入口位置，或改用千牛入口 |

## 7. 执行记录规范

每步操作后记录：`时间 | 动作 | 结果(OK/FAIL) | 截图文件`。
执行结束输出执行报告：完成的模块、跳过的模块及原因、待用户确认事项。
