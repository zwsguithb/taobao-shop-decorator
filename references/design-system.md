# 装修设计规范（Design System）

> 用途：为装修规格生成与 AI 生图提供风格、色系、尺寸、文案与 prompt 依据。

## 1. 风格库

| 风格 | 适用类目 | 视觉特征 | 默认主色 |
|---|---|---|---|
| 简约 | 数码/家居/服饰 | 大留白、细线条、单主色、无装饰 | #1F2937（深灰） |
| 潮酷 | 潮流服饰/鞋包 | 高对比撞色、粗字体、几何元素 | #111111 + 荧光色 |
| 母婴 | 母婴/童装 | 圆角、柔和渐变、可爱插画 | #FFB6C1（粉）+ #87CEEB（蓝） |
| 美妆 | 美妆/个护 | 渐变光感、轻奢质感、柔光 | #E8A0BF（玫粉） |
| 食品 | 食品/生鲜 | 暖色调、食欲感、实拍风 | #FF7A45（暖橙） |
| 家居 | 家居/家纺 | 低饱和、自然质感、生活方式场景 | #8B9D83（灰绿） |
| 数码 | 数码/3C | 深色背景、科技感光效、简洁 | #0F172A（深蓝黑） |
| 节日营销 | 全类目 | 节日元素（春节红/圣诞红绿/618 紫）、氛围光效 | #E60012（中国红） |

## 2. 色系表（主色 + 辅色建议）

| 色系 | 主色 HEX | 辅色 1 | 辅色 2 | 文字/背景建议 |
|---|---|---|---|---|
| 中国红 | #E60012 | #FFD700（金） | #FFF5F0 | 白字红底 / 深灰正文 |
| 活力橙 | #FF7A45 | #FFC53D | #FFF7E6 | 白字橙底 |
| 清新绿 | #52C41A | #A0D911 | #F6FFED | 深绿正文 |
| 科技蓝 | #1677FF | #69B1FF | #E6F4FF | 白字蓝底 |
| 高级黑金 | #1F1F1F | #D4AF37 | #F5F0E6 | 金字黑底 |
| 温柔粉 | #FF85C0 | #FFC9E8 | #FFF0F6 | 深玫红正文 |
| 莫兰迪灰 | #8C8C8C | #D9C7B2 | #F5F1EB | 深灰正文 |
| 淘宝橙 | #FF5000 | #FFB800 | #FFF7F0 | 白字橙底（平台识别色） |

规则：
- 同一店铺**最多 3 色**（主色 + 2 辅色），避免花哨。
- 正文文字用深色系（#1F2937 / #333），背景浅色时保证对比度 ≥ 4.5:1。
- 按钮/CTA 用主色填充 + 白色文字。

## 3. 尺寸规范（750 设计稿基准）

手机端淘宝装修统一按 **750px 宽**设计稿：

| 素材类型 | 尺寸 | 说明 |
|---|---|---|
| 店铺头图 Banner | 750 × 420 | 首页顶部，可含 Logo+标语 |
| 轮播图 | 750 × 420 | 单张，建议 3-5 张成套 |
| 导航图标（含文字） | 150 × 150 | 一行 4-5 个 |
| 营销活动图 | 750 × 400 | 活动海报 |
| 商品主图 | 750 × 750 | 方图 |
| 商品卡片 | 750 × 750（图）+ 标题区 | 后台自适应 |
| 详情长图 | 750 × N | N 建议 ≤ 1500/段 |
| 优惠券图 | 750 × 300 | 券面展示 |
| 客服图标 | 120 × 120 | 入口图标 |

导出要求：JPG 或 PNG，单张 ≤ 3MB（图片空间限制），RGB 模式，无透明通道问题。

## 4. 文案规范

- 头图主标题 ≤ 8 字，副标题 ≤ 14 字，行动号召 ≤ 6 字（如「立即抢购」「新品首发」）。
- 导航文字 2-4 字（新品/热卖/清仓/优惠券/客服）。
- 商品分组标题 ≤ 10 字，可加促销前缀（「限时 5 折」）。
- 公告 ≤ 20 字/条，滚动展示。
- 全店文案统一语气：电商促销风（简洁、行动导向、避免夸大违规词）。
- **禁用违规词**：绝对化用语（最/第一/顶级/全网最低）、虚假承诺、医疗功效断言等广告法违规表述。

## 5. AI 生图 prompt 模板

通用结构：`[场景] + [主体] + [风格] + [色系] + [构图] + [文字要求] + [负面约束]`

示例（简约数码风 Banner）：
```
手机店铺首页 Banner，深蓝黑(#0F172A)渐变背景，一款白色无线耳机悬浮居中，
极简科技风，细线条光效，左下角留白用于标题文字"降噪新旗舰"，
画面干净，无文字叠加（文字后续由设计添加），高清电商主图风格
```

示例（母婴风轮播图）：
```
淘宝母婴店轮播图，柔粉色(#FFB6C1)到天蓝(#87CEEB)柔和渐变背景，
圆角插画风格的小熊与婴儿用品元素散落，中央留白，
温馨可爱氛围，无文字，电商 banner 构图，750x420 比例
```

生成规则：
- **默认不在图上生成文字**（AI 文字易出错），文字由规格中的文案层单独标注；若必须带字，明确给出完整文案且要求简体中文。
- prompt 中显式给出主色 HEX 或色名 + 场景 + 主体 + 留白位置。
- 负面约束统一加：`无其他品牌 Logo、无明星肖像、无水印、无乱码文字`。

## 6. 商品图处理

- 用户提供商品图时，优先原图直接使用（方形图适配 750×750）。
- 非方图需处理：居中裁切为方形，或按模块要求输出对应尺寸。
- 商品图不建议 AI 重绘（真实商品需保真），AI 生成仅用于氛围/背景合成时保留商品主体。
